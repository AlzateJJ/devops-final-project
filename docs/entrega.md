## Qué entregar al profesor

El enunciado exige tarjetas de Trello y los archivos HTML5, CSS, JSON y recursos necesarios para ejecutar el sistema. La entrega práctica consiste en:

1. **ZIP completo del proyecto:** incluye HTML, CSS, JavaScript, JSON, logos, diagramas, guías y demás archivos necesarios. Adjunta `entrega/devops-atlas-entrega.zip` en MinasLap; un enlace a la web publicada por sí solo no contiene la entrega de archivos solicitada.
2. **Enlace al tablero de Trello:** https://trello.com/b/5CSrY3pF/devops-tools-project. Comprueba que el profesor pueda acceder al tablero.
3. **Enlaces complementarios:** el repositorio https://github.com/AlzateJJ/devops-final-project y la web de GitHub Pages si ya está publicada. Facilitan revisar el código y demostrar la aplicación, pero no sustituyen los archivos exigidos.

El PDF no exige un informe escrito separado, un video ni una presentación adicional. Revisa también los campos e instrucciones de la actividad en MinasLap por si el profesor añadió indicaciones allí.

## Paquete

`entrega/devops-atlas-entrega.zip` contiene las carpetas necesarias, el lanzador de Windows, la guía principal y un manifiesto SHA-256. También incluye `historial-commits.txt` generado desde el repositorio. El manifiesto externo `entrega/manifiesto-entrega.json` identifica el commit y el checksum del ZIP.

El paquete no incluye `node_modules`, perfiles de Chrome, archivos temporales ni credenciales. Para ejecutar solo se necesita Node.js y Chrome. Para regenerar contenido se requieren los scripts y las dependencias de desarrollo indicadas en la guía.

## Presentación sugerida al profesor

1. Mostrar el esquema preconceptual y sus seis enlaces dinámicos.
2. Consultar una herramienta, su fuente, logo, categoría y modelo de precio.
3. Registrar y editar una herramienta y una práctica con imagen.
4. Relacionarlas mediante un uso que explique el aporte a cultura DevOps; editar el uso.
5. Recargar para demostrar persistencia.
6. Mostrar en Prácticas los 14 diagramas de sus fichas y los 5 de «Material de apoyo Essence».
7. Mostrar el tablero y revisar el historial y las evidencias.
